Imagens

Baixe, organize e limpe imagens OCI; veja digest, tamanho e uso antes de remover, e importe ou exporte arquivos tar quando precisar mover imagens entre hosts.

PodStack 0.1.2Documentação de usuário

Visão geral

A seção Images lista as imagens do storage do Podman com REPOSITORY:TAG, DIGEST, SIZE e USO (quantidade de containers que usam a imagem). O pull mostra progresso por camada e pode ser cancelado; a plataforma pode ser escolhida antes do download.

Imagens baixadas fora do PodStack também aparecem. O PodStack não tem registry próprio: o pull e o push usam o Podman e as credenciais já configuradas no host.

Na interface

Pull e importação

  1. Abra Images na barra lateral.
  2. Clique em Pull.
  3. Informe a Imagem, por exemplo nginx:alpine.
  4. Escolha a plataforma em Automático, linux/amd64, linux/arm64, linux/arm/v7, linux/ppc64le ou linux/s390x.
  5. Clique em Pull e acompanhe o progresso. Enquanto o pull está ativo, o botão vira Cancelar.

Para importar um arquivo tar, clique em Importar, selecione o arquivo e confirme. O seletor aceita *.tar, *.tar.gz e *.tar.zst; o carregamento é feito pelo engine.

Tags e remoção

Selecione uma imagem e use Tag ou Untag. O diálogo Tag da imagem mostra a referência atual e um campo Nova referência; Aplicar cria a tag e Remover tag remove a referência indicada. A imagem em si continua no storage até ser removida.

O botão Remover pede confirmação. Containers em uso bloqueiam a remoção, a menos que a operação use --force pela CLI. Para remover várias imagens, use a multi-seleção e a ação em lote.

Prune com prévia

Prune abre uma prévia com as imagens sem uso, o tamanho de cada uma e o total recuperável estimado. A GUI executa o prune de imagens dangling; a lista também distingue imagens sem uso e em uso, mas nenhum mountpoint é exposto. Imagens usadas por containers existentes não são afetadas.

Prune é destrutivo

O prune remove imagens sem uso do storage. Containers existentes não são afetados, mas a imagem precisará ser baixada novamente se você quiser recriar um container a partir dela. A CLI aceita --all para incluir imagens sem uso que não são apenas dangling.

Na CLI

podstack images sem subcomando é o mesmo que images ls. Os comandos images não aceitam --json nesta versão; images inspect sempre imprime o JSON bruto.

Comando Flags O que faz
podstack images ls / list — Lista repositório:tag, ID, tamanho e containers.
podstack images pull <imagem> --platform p Baixa com progresso por camada; Ctrl+C cancela.
podstack images push <id> --destination <repo> (obrigatório) Envia para um registry usando as credenciais do host.
podstack images rm <id> --force Remove a imagem; --force ignora a checagem de uso.
podstack images prune --all Remove imagens sem uso; sem --all, apenas dangling.
podstack images history <id> — Mostra camadas, tamanho e comando de criação.
podstack images tag <id> <repo:tag> — Cria uma nova referência.
podstack images untag <id> <repo:tag> — Remove uma referência.
podstack images inspect <id> — Imprime o JSON bruto da imagem.
podstack images export <id> <arquivo> — Exporta para tar.
podstack images load <arquivo> — Importa um tar. 
podstack images pull nginx:alpine
podstack images pull --platform linux/arm64 alpine:3.20
podstack images
podstack images tag 1b75f92cc711 local/nginx:dev
podstack images history 1b75f92cc711
podstack images inspect 1b75f92cc711 | head -40
podstack images export 1b75f92cc711 /tmp/nginx.tar
podstack images load /tmp/nginx.tar
podstack images push 1b75f92cc711 --destination registry.example.com/equipe/nginx:dev
podstack images prune --all

Limitações

  • A GUI não tem push, history, inspect nem export; esses fluxos estão apenas na CLI.
  • O prune da GUI remove dangling images. Para remover todas as imagens sem uso, use podstack images prune --all.
  • Não há tela de login de registry. O pull/push usa as credenciais já configuradas no Podman/containers-auth.
  • O digest aparece na lista, mas não há uma página de detalhe de imagem na GUI.
  • Imagens em uso bloqueiam a remoção; o --force existe na CLI e deve ser usado com cuidado.
