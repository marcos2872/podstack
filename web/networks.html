Redes

Crie redes bridge, defina subnet e gateway e conecte containers para isolar ou organizar serviços — com aliases DNS pela CLI.

PodStack 0.1.2Documentação de usuário

Visão geral

A seção Networks lista as redes do Podman com NAME, DRIVER, SUBNET e CONTAINERS. A rede podman é criada pelo engine e aparece por padrão.

Uma rede bridge permite que os containers se encontrem pelo nome ou alias. Containers conectados bloqueiam a remoção da rede. A subnet é opcional; quando informada, precisa ser um CIDR válido e não pode sobrepor outra rede.

Na interface

  1. Abra Networks na barra lateral.
  2. Clique em Criar, informe Nome, Subnet (CIDR, opcional) e Gateway (opcional); confirme em Criar.
  3. Para conectar um container, selecione a rede e clique em Conectar; informe o Container (ID ou nome) e confirme.
  4. Para desconectar, selecione a rede e clique em Desconectar; informe o container e confirme.
  5. Para remover, selecione a rede e clique em Remover; confirme no diálogo.

A GUI cria redes com o driver padrão (bridge), aceita subnet e gateway, mas não expõe aliases, IPv6 nem a escolha de driver. Para esses recursos, use a CLI. A multi-seleção permite remover várias redes, mas redes com containers conectados continuam bloqueadas.

Aliases são um recurso da CLI

O alias DNS de um container na rede é definido em podstack networks connect ... --alias. A GUI conecta e desconecta sem alias. Se você precisa de api apontando para um container específico, use a CLI ou o Compose.

Na CLI

Comando Flags O que faz
podstack networks ls / list — Lista nome, driver, subnet e containers.
podstack networks create <nome> --subnet CIDR, --gateway IP, --driver driver, --ipv6 Cria uma rede com os parâmetros informados.
podstack networks rm <nome> --force Remove a rede; containers conectados bloqueiam.
podstack networks connect <rede> <container> --alias a (repetível) Conecta o container e adiciona aliases DNS.
podstack networks disconnect <rede> <container> --alias a Desconecta o container; o alias é opcional. 
podstack networks create backend --subnet 10.89.0.0/24 --gateway 10.89.0.1
podstack networks create backend-v6 --ipv6
podstack networks connect backend web --alias api --alias web
podstack networks ls
podstack networks disconnect backend web --alias api
podstack networks rm backend

Referência rápida

Ação Na GUI Na CLI
Listar Networks podstack networks ls
Criar com subnet/gateway Criar → nome/subnet/gateway podstack networks create --subnet --gateway
Escolher driver / IPv6 — (use a CLI) --driver, --ipv6
Conectar container Conectar → container podstack networks connect
Definir aliases — (use a CLI) --alias (repetível)
Desconectar Desconectar → container podstack networks disconnect
Remover Remover → confirmar podstack networks rm [--force]

Limitações

  • A GUI não expõe aliases, IPv6 nem driver; use a CLI para esses parâmetros.
  • Redes com containers conectados não podem ser removidas; desconecte os containers antes.
  • Não há edição de subnet/gateway depois da criação; recrie a rede ou use a CLI.
  • A rede padrão do Podman aparece na lista, mas o PodStack não gerencia a rede podman como uma rede de projeto.
